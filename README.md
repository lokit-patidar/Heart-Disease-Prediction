❤️ Heart Disease Prediction Web App

A full-stack Machine Learning web application that predicts the likelihood of heart disease using a TensorFlow neural network. Users can enter clinical parameters through a modern React interface, and the application provides a real-time prediction along with the model's confidence score.

✨ Features

- Predicts the likelihood of heart disease using a trained TensorFlow model.
- Displays the prediction probability.
- Modern and responsive user interface built with React and Tailwind CSS.
- Flask REST API for real-time inference.
- Interactive form with clinical parameters.
- Clean and intuitive design.

⚙️ Installation

Clone the repository

git clone https://github.com/lokit-patidar/Heart-Disease-Prediction.git
cd Heart-Disease-Prediction

Backend Setup

cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt

python app.py

Backend runs at:

http://127.0.0.1:5000

Frontend Setup

cd frontend

npm install

npm run dev

Frontend runs at:

http://localhost:5173

---

🔌 API Endpoint

POST "/predict"

Sample Request

{
  "Age": 45,
  "Sex": "M",
  "ChestPainType": "ATA",
  "RestingBP": 130,
  "Cholesterol": 250,
  "FastingBS": 0,
  "RestingECG": "Normal",
  "MaxHR": 170,
  "ExerciseAngina": "N",
  "Oldpeak": 0,
  "ST_Slope": "Up"
}

Sample Response

{
  "prediction": "No Heart Disease",
  "probability": 0.12
}
